# Historical archives

Original source/result ZIP files preserved byte-for-byte. SHA-256 identities and
byte sizes are recorded in `../evidence/SOURCES.json`. These are historical
records, not the active package. Some contain absolute sandbox paths or
unfinished development approaches; do not mistake them for supported entry points.

The active software lives in `src/iap`; modern commands/configurations are in
the root README. Gate 0/1 archives have integrity coverage only in this release;
Gate 2E/2F arithmetic and the selected numerical regressions are separately
identified under `validation/`.
