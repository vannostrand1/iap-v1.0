# Experimental history and release scope

The early Gate 0/1 archives preserve the development path from compact tables
through learned codecs, hypothesis evaluation, proposal learning and induced
symmetry grammars. They remain historical prototypes, not one frozen algorithm
and not newly rerun evidence in IAP v1.0.

The active release focuses on the later Convention Relay line:

| Stage | Question | Where preserved |
|---|---|---|
| Gate 2A live Doom | Does correct culture accelerate live gameplay? Not demonstrated in supplied confirmation | `evidence/doom_basic_live/` |
| Gate 2B full-level Doom | Can a useful teacher be learned? Initial smoke regressed | Context retained in limitations; engine not part of this release |
| Gate 2B Convention Relay | Is a symbolic convention absorbed into recipient gains? | Original archive + evidence |
| Gate 2C | Does it cross architectures with aligned interfaces? | Original archive + `gate2c_aligned.json` |
| Gate 2D | Unknown signed coordinate/action permutation | Original archive + `gate2d_permutation.json` |
| Gate 2E | Nonlinear coordinates; shared relational chain ontology | Original archive + relational/stress configurations |
| Gate 2F | Different bounded state/action granularity | Original archive + historical/matched/fresh configurations |

Gate 2F does not integrate every learned proposal component from Gate 1H. Its
grounder is a separately authored combinatorial ontology solver. Do not imply
that a single unchanged learned system passed the entire historical ladder.
The two different Gate 2B tasks are explicitly disambiguated by name.
