# Frozen Gate 2E protocol

## Task
Convention Relay: 8 contexts × 3 sequential stages × 2 actions. The source teacher policy is already learned and distilled into the upstream 97-byte IAP packet.

## Alien interface
For each replicate:
- permute anonymous context-chain identities;
- optionally swap the two action labels;
- replace the six source sensor coordinates with 8 dense nonlinear mixed channels;
- normalize using recipient-local statistics only.

No source sensor coordinate is passed through directly.

## Relational culture capsule
- 97-byte teacher policy packet;
- 144-byte source relational atlas;
- total 241 bytes excluding framing.

## Grounding
The receiver observes its own three-step temporal chains and receives at most 18 reward-bearing active calibration queries. It maintains source↔local chain compatibility under both action-label conventions and uses perfect-matching feasibility to eliminate inconsistent hypotheses. It never receives the hidden context permutation, action swap, or sensor transform.

## Absorption
After grounding, recipient gets 512 cultural observations sampled from its own alien sensor states and the grounded packet Q-targets. Environmental reward is zero/absent during this phase. The message is removed before final evaluation.

## Primary directions
- Transformer teacher → Fly recipient, alternating graph substructures 223/239.
- Fly teacher → Transformer recipient.

12 fresh alien worlds per direction.

## Controls
1. Same packet, but no semantic grounding: assume local chain identity and action labels already match the source.
2. Same 18 reward-query states, no packet: recipient trains for the same 512 update budget only on queried reward labels.

## Stress condition
Repeat grounded transfer with a five-dimensional nonlinear recipient interface. This removes the possibility of a globally invertible ambient 6-D→5-D coordinate map while retaining distinct finite task states.
