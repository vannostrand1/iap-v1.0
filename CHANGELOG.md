# Changelog

## 1.0.0 — 2026-09-19

First consolidated research release for the Convention Relay IAP branch.

- Installable `src/iap` package and `iap` CLI, independent of old sandbox paths.
- Explicit public-world, oracle, grounder, learner and evaluator boundaries.
- Strict 97-byte policy / 241-byte capsule readers and checksummed v1 envelopes.
- Aligned, signed-permutation, nonlinear relational and bounded-ontology tasks.
- MLP, feature-token Transformer and existing-edge-gain FlyWire-derived models.
- Packet-free student checkpoints, byte manifests, progress events and trial resume.
- Separate historical-offset and matched-initialization configurations.
- Reward/label-query, exposure, batch-example and wire-byte accounting.
- Byte-preserved historical archives, arithmetic audit and numerical validation.
- CPU-first Windows launchers, tests, build configuration and GitHub CI workflow.

all historical gates one unchanged algorithm. Later fresh confirmation must
remain distinct from imported evidence and numerical regression tests.
